# TOEIC homework

One week of practice for one student, as a single self-contained page.

Generated — do **not** edit `index.html` here. Edit the template or the
student's JSON in the private `_build/` folder and re-run:

    node _build/build.mjs

The page contains no answer key and no test content: only the student's own
per-part percentages, which they have already seen on their score report.
